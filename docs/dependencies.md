# ATLAS-EO Dependency Audit & Rationale

| Dependency | Category | License | Rationale & Justification |
| :--- | :--- | :--- | :--- |
| **FastAPI** | Backend Web Framework | MIT | High-performance, async-first web framework with automatic OpenAPI documentation. |
| **Uvicorn** | ASGI Server | BSD-3-Clause | Production-grade, lightning-fast ASGI web server. |
| **Pydantic v2** | Data Validation | MIT | Strict data validation, environment settings management, and ultra-fast Rust core. |
| **Structlog** | Logging | Apache 2.0 / MIT | Structured JSON logging with context variable correlation support. |
| **SQLAlchemy 2.x** | Database ORM | MIT | Modern async-first Object Relational Mapper for PostgreSQL. |
| **Asyncpg** | DB Driver | Apache 2.0 | High-performance asynchronous PostgreSQL database driver. |
| **Alembic** | DB Migrations | MIT | Version-controlled relational database schema migration tool. |
| **Redis** | Cache/Queue | BSD-3-Clause | Memory-first store for caching, session management, and rate limiting. |
| **Qdrant-Client** | Vector Database | Apache 2.0 | Vector database SDK for literature embeddings and semantic search retrieval. |
| **HTTPX** | HTTP Client | BSD-3-Clause | Async HTTP client for external service integration and API testing. |
| **Pytest** | Testing Framework | MIT | Robust test runner supporting async fixtures and coverage reporting. |
| **Ruff** | Linter / Formatter | MIT | Blazing fast Rust-based Python linter replacing Flake8, Black, and Isort. |
| **MyPy** | Static Type Checker | MIT | Strict static type checker enforcing 100% type safety. |
